# Main rack Scale Quantizer migration boundary

The old Main rack `scale_quantizer_runtime.lua` has six scales: major, minor, dorian, mixolydian, pentatonic, and chromatic pass through. Root is a MIDI pitch class from 0 to 11. Direction is nearest, up, or down. Parameters clamp and round to integer selections. The original Lua rack tests confirm C♯4 becomes C4 in C major nearest mode and D4 in up mode.

The nearest calculation searches degrees in the input note's normalized octave only. For example, B4 in C minor maps to B♭4 instead of the closer C5. V2 preserves this behavior so saved settings and event output remain comparable. Up/down modes wrap to the next or previous octave when needed. The result clamps to MIDI 0–127.

The old `export_midi_effects.scale_quantizer` adapter owns eight note slots. On a relevant parameter change, it sends note offs for every held output, refreshes the rack, then sends note ons for every held input, including notes whose pitch has not changed. The [read-only legacy probe](../tools/legacy-midi-scale-quantizer.lua) and the [Rust event trace](../artifacts/reviews/checkpoint-100-midi-scale-quantizer-events.json) agree on the resulting eight event sequence. V2 keeps this retrigger behavior for the first port. The separate keyboard and MIDI input manager still owns device state and sustain; the Rust effect owns its own mapping and emits at the incoming sample offset.

[`MidiScaleQuantizer`](../crates/manifold-core/src/midi_scale_quantizer.rs) uses the fixed eight-slot router and caller-owned 16-event buffer used by the earlier MIDI effects. `MidiInput → MidiScaleQuantizer → VoiceSynth` is a typed Rust graph route; MIDI events are dispatched without audio-thread allocation. The [browser workbench](../projects/midi-scale-quantizer/project.json) shows the input and bounded Rust output trace. Its on-screen keyboard works inside the embedded browser without Web MIDI permission. Hardware MIDI requires a browser that permits `requestMIDIAccess()`; the workbench offers a URL to open externally.

One native Rust audio fixture holds C♯4 and E4 while changing from nearest to up. Old Lua and the Rust graph emit the same note sequence; native Rust, direct Wasm, AudioWorklet, and the workbench comparison renderer match all 8,192 stereo frames exactly. See [checkpoint 100](../artifacts/reviews/checkpoint-100.md). This proves the event transform and this audio route, not the old Lua UI layout or a JUCE/C++ renderer.
