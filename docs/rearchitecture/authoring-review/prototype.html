Which names can I choose?

device is our ordinary JavaScript variable name. Every later device.input or device.control refers to the same object declared above. You could call it spectralShift and update those uses consistently.

const spectral = device.add('spectral', phaseVocoder);
const — JavaScript
Declares a name that cannot be reassigned. The object it refers to can still be configured.
device and the spectral on the left — our local names
device was declared earlier. spectral names the processor instance returned by this call.
The quoted 'spectral' — stable authored identity
This names the processor inside the device for saved identity and lookup. Renaming a local variable does not require changing this string.
phaseVocoder — imported definition
The import at the top brings this processor definition from Manifold into the script.
add — Manifold API
A method supplied by Manifold. The parentheses call it with the values inside.

What is proved, and what remains

Real JS/TS imports, inferred parameter/port members, default controls, semantic identity, source navigation, save/reopen and accepted values have automated coverage. The three audio examples also render through the existing native and Wasm engines in an offline comparison.

This prototype handles stereo audio buses and one MIDI input. Wider boundary types, nested Device composition, visual graph rewriting, custom presenter helpers and public package publication remain follow-up work. Existing graph tooling stays available through manifold/graph.
