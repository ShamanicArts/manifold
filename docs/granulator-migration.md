# Granulator migration boundary

The original `dsp/core/nodes/GranulatorNode.cpp` captures stereo input in a four-second ring and can run 64 concurrent grains. Each grain has its own read position, pitch increment, age, and envelope. Rust graph kind 51 ports that capture-ring path with per-sample 10 ms smoothing for grain size, density, position, pitch, spray, and mix. Freeze, enable, and five envelope choices are immediate controls. The [workbench](../projects/granulator/project.json) starts at a short capture position so the live test becomes audible quickly. Prepared storage and generation stamps clear history at a type switch without allocation on the audio callback.

Eleven C++ captures cover default ring behavior, short grains, size, density and pitch sweeps, an envelope change, freeze, mix, and 64-frame blocks. All eleven match Rust/Wasm within `2.38e-7` maximum sample difference. The C++ reference runner supplies a stub random value of `0.5` and sets spray to zero, so the original node’s random draw does not affect these comparisons. Rust uses a fixed 48-bit seed for repeatable nonzero spray. Standalone FX type 11 maps normalized `p/0` to `12…280 ms`, `p/1` to `2…64` grains/s, `p/2` to position, and `p/3` to spray; `p/4` is unused. Its pitch remains 0 st, envelope Hann, internal mix fully wet, and freeze off. Four new slot cases compare native Rust with Rust/Wasm.

The original node also accepts a file or copied capture as a separate source buffer, with a source region control. Three additional C++ captures exercise the copied-source path, source-region changes, pitch, and envelope. The browser now decodes a chosen file at 48 kHz, uploads it before audio starts through the existing sample ABI, and shows the source-region controls only while a file is selected. Rust moves the prepared PCM into Granulator and resamples it to the graph sample rate when needed. The source never takes a lock or allocates in `process_planar`. Clearing the file on a stopped view restores live capture. A stopped Loop Capture take can now be copied into Granulator through the browser host and consumed by the same prepared source path. Buffer duration is fixed at the original four-second default for the current graph kind; changing it would require a prepared graph replacement. Full Standalone FX project routing and preset roundtrips remain separate work.
