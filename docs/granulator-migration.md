# Granulator migration boundary

The original `dsp/core/nodes/GranulatorNode.cpp` captures stereo input in a four-second ring and can run 64 concurrent grains. Each grain has its own read position, pitch increment, age, and envelope. Rust graph kind 51 ports that capture-ring path with per-sample 10 ms smoothing for grain size, density, position, pitch, spray, and mix. Freeze, enable, and five envelope choices are immediate controls. The [workbench](../projects/granulator/project.json) starts at a short capture position so the live test becomes audible quickly. Prepared storage and generation stamps clear history at a type switch without allocation on the audio callback.

Eight C++ captures cover default ring behavior, short grains, size, density and pitch sweeps, an envelope change, freeze, mix, and 64-frame blocks. All eight match Rust/Wasm within `2.38e-7` maximum sample difference. The C++ reference runner supplies a stub random value of `0.5` and sets spray to zero, so the original node’s random draw does not affect these comparisons. Rust uses a fixed 48-bit seed for repeatable nonzero spray. Standalone FX type 11 maps normalized `p/0` to `12…280 ms`, `p/1` to `2…64` grains/s, `p/2` to position, and `p/3` to spray; `p/4` is unused. Its pitch remains 0 st, envelope Hann, internal mix fully wet, and freeze off. Four new slot cases compare native Rust with Rust/Wasm.

The original node also accepts a file or copied capture as a separate source buffer, with a source region control. That source handoff is not wired to this graph kind yet. File decoding and ownership transfer should use the existing sample-region upload path, then expose a prepared, immutable source to Granulator without mutex or allocation in `process_planar`. Buffer duration is fixed at the original four-second default for the current graph kind; changing it would require a prepared graph replacement. Full Standalone FX project routing and preset roundtrips remain separate work.
