# Checkpoint 105 — temporal source partials

Open the [temporal comparison page](http://127.0.0.1:4173/temporal-partials-review.html) to inspect matching C++ and Rust partials across four sources and their time frames. The [playable Sine bank](http://127.0.0.1:4173/?primitive=sine-bank) now analyzes a chosen audio file or a built-in two-tone source in a Rust/Wasm worker, shows its partials over time, and auditions any prepared frame through the existing bank.

The [Rust extractor](../../crates/manifold-core/src/temporal_partials.rs) bounds output to 128 frames × 32 partials and retains source rate, region, absolute frame position, pitch confidence, RMS, and brightness. Tonal input uses harmonic projections; unpitched input uses the original extractor's log-band FFT peak selection and amplitude projections. Source decoding, pitch analysis, and partial extraction run outside the audio callback. The [worker transport](../../web/src/audio/sample-analysis-worker.js) transfers bounded typed arrays; the AudioWorklet receives only a selected partial target. Unpitched audition keeps the detected absolute frequencies instead of treating the strongest spectral peak as a musical pitch.

The [legacy runner](../../tools/legacy-temporal-partials-reference.cpp) compiles the original `PartialsExtractor.h` and JUCE FFT code from `my-plugin`. Its supplied pitch decision isolates the extractor: 220 Hz for the two-tone source, no reliable pitch for broadband noise, transient, and silence. The [fixture manifest](../../web/public/reference/temporal-partials/manifest.json) identifies four deterministic 48 kHz stereo sources and the old source hash. These captures do not test the old pitch detector, complete sample playback object, Add/Morph recipe, or phase vocoder.

The [comparison report](checkpoint-105-temporal-comparison.json) covers 36 temporal frames. Every frame has the same ordered partial count as C++; all 312 emitted partial slots match by index. Worst frequency error is 0.0043 Hz, amplitude error 5.49×10⁻⁶, and circular phase error 0.00058 rad. Frame position, RMS, and brightness agree within the gate's 10⁻⁵ tolerance. Silence emits no partials. Rust's separate pitch summary estimates 220.002 Hz on the tonal case, while the reference harness supplies exactly 220 Hz.

Verification: 112 Rust workspace tests, Wasm build and direct ABI probe, worker transport and summary-mode probe, C++ capture regeneration, strict ordered comparison, Vite build, and a headless browser load of the served review page pass. A 30-second tone takes about 266 ms for 128 frames in direct Wasm on this machine; this is a worker measurement, not an audio callback timing guarantee.
