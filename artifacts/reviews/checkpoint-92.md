# Checkpoint 92 · Stereo Widener host switch and browser MIDI feedback

The [FX host switch workbench](http://127.0.0.1:4173/?primitive=standalone-fx-host) now includes Stereo Widener. The [return-visit waveform](checkpoint-92-widener-return.png) overlays the old C++ graph and Rust output around the return switch; the lower panel shows their absolute sample difference. [Native metrics](checkpoint-92-widener-switch-metrics.json) and [Rust/Wasm metrics](checkpoint-92-widener-wasm-metrics.json) report a maximum difference of **3.73e-8** over 32,768 stereo frames. The old Widener `prepare()` clears its low-band filters and correlation meter each time the graph switches; Rust host mode now mirrors that reset while the Delay tail remains available.

I tested the old Lua mixer's lower input count during Delay → Reverb switching. [The eight-bus capture](checkpoint-92-reverb-low-bus-metrics.json) is byte-identical to the prior capture with 11 active buses. Old `GraphRuntime` clamps out-of-range route buses onto the last active bus, and this slot configures every bus with the same gain and pan. Per-bus gain/pan variants remain unmeasured; there is no new bus mask in Rust.

The [Voice synth](http://127.0.0.1:4173/?primitive=voice) and [Sample instrument](http://127.0.0.1:4173/?primitive=sample-instrument) already request Web MIDI on an explicit click. In the in-app browser, the request can remain pending without a permission prompt. The button now becomes **Stop waiting for MIDI** during that request and can recover immediately; a late permission result cannot connect after cancellation. After four seconds, the page points to a selectable external-browser URL. The on-screen keyboard remains available without MIDI permission. This change does not grant MIDI permission to the in-app browser itself.

Verification: `python3 scripts/probe-fx-widener-switch.py`, `node scripts/verify-fx-widener-wasm.mjs`, `node scripts/test-midi-input.mjs`, 89 Rust workspace tests, Rust formatting, and the Vite build. The in-app browser automation backend was unavailable in this session, and headless Chromium stopped responding after initial page load, so live visual confirmation of this checkpoint remains pending. Workbench totals: 45 views, **383 offline cases** (239 C++ and 144 native Rust references). The graph capture reconstructs the old Lua slot layout with old C++ runtime and nodes; it does not execute the Lua binding or deferred worker.
