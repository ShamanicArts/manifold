# Checkpoint 51 · Legacy WaveShaper and Standalone FX type 2

[Open WaveShaper](http://127.0.0.1:4173/?primitive=waveshaper) · [Open Standalone FX](http://127.0.0.1:4173/?primitive=standalone-fx) · [WaveShaper screenshot](checkpoint-51-waveshaper.png) · [FX slot screenshot](checkpoint-51-standalone-fx.png) · [Browser metrics](checkpoint-51-metrics.json) · [Migration boundary](../../docs/waveshaper-migration.md)

The original Standalone FX type 2 is `WaveShaperNode`, which differs from the v2 Distortion primitive. This checkpoint ports all seven original curves, smoothing, bias, dry/wet mix, pre/post tone filters, and the legacy 1×/2×/4× coefficient behavior to an allocation-free Rust kernel. Graph kind 37 exposes all eight node parameters. The browser has a standalone live WaveShaper view and the Standalone FX slot now accepts legacy type 2 with its four normalized controls and unused fifth control. JavaScript owns the controls and visuals; Rust/Wasm owns audio processing.

Eleven cases captured directly from the original C++ node all show **Match** against Rust/Wasm, including all curves, a curve switch, filter sweep, mode change, and short blocks. The largest maximum sample difference in this family is `4.47e-7` (foldback), far below the shared `2e-4` threshold. Four additional native Rust cases exercise Standalone FX type 2 controls and a type switch. The expanded slot's largest maximum difference is `9.69e-7` across its 23 cases. The complete browser sweep passes **204 cases across 29 views**, with zero page errors. The 70 Rust workspace tests, Wasm build, and web build pass. Live browser checks started test audio, selected Foldback and 4× coefficient mode, set drive to 24 dB, and switched the running slot to Shape; the relevant controls appeared.

The old scalar “oversampling” branches do not upsample audio. Their only effective difference is filter coefficient scaling. The Rust port preserves this behavior for parity without allocating unused buffers. The original C++ node updates shared parameter smoothing while processing left then right; the port preserves that stereo order. The C++ comparisons establish node parity; the slot comparisons establish native Rust/Wasm parity, not full legacy project routing or preset parity. Other 14 Standalone FX type IDs remain unavailable.
