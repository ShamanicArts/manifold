# Checkpoint 94 · Standalone Transpose MIDI effect slice

The [MIDI Transpose workbench](http://127.0.0.1:4173/?primitive=midi-transpose) now plays keyboard or permitted Web MIDI notes through a Rust event transformer and the eight-voice synth. Its Transpose slider spans `−24…24` semitones. Holding a note while changing the value releases the old output note and starts the mapped note at the next audio block. The page’s note monitor shows incoming keys; the [audio and output-note timeline](checkpoint-94-midi-transpose.png) shows a held C4 entering as G4 and remapping to C3 at frame 2,048.

The [offline old Lua adapter versus native Rust trace](checkpoint-94-midi-transpose-events.json) matches **all 25 output events exactly**. It covers held-note remapping, output clamping, an eighth-to-ninth-note eviction, all notes off, and pitch bend forwarding. The old Lua files run only in the offline probe with stubbed host services; v2 loads no Lua.

The [native Rust versus Rust/Wasm audio comparison](checkpoint-94-midi-transpose-wasm-metrics.json) matches **all 8,192 stereo frames exactly**. A separate Node test runs the actual AudioWorklet adapter with a minimal Web Audio host shim and also matches the native fixture exactly. The Rust transform uses eight fixed slots and caller-provided output storage; its event path allocates no heap memory. The workbench offers 46 views and 385 offline cases (240 C++ and 145 native Rust audio references), plus this old Lua MIDI event trace.

Verification: `python3 scripts/probe-midi-transpose.py`, `python3 scripts/generate-midi-transpose-reference.py`, `node scripts/verify-midi-transpose-wasm.mjs`, `node scripts/verify-midi-transpose-worklet.mjs`, 92 Rust workspace tests, formatting, Wasm build, and Vite build. The local page and fixture URLs respond, but rendered browser interaction was not confirmed in this session: the in-app browser backend is unavailable, and the headless Chromium run timed out before the static module title could be read. Hardware MIDI still depends on browser permission; the on-screen keyboard works without it. Native MIDI output and general MIDI graph edges remain to be built.
