# Checkpoint 88 · Ring Modulator optional-bus behavior

The reconstructed old Standalone FX graph connects only the Ring Modulator carrier. Old `GraphRuntime` nevertheless supplies views for both inputs declared by `RingModulatorNode`; its unconnected second bus is silent. The node treats that view as an external modulator. At the slot defaults of full depth, internal wet mix, and public wet mix, the old branch output is silent. This is an observable graph behavior, not a desired default for the new product.

Before the compatibility fix, the Rust host-switch path ran Ring's internal oscillator and differed from the old C++ graph by **0.308** maximum. The explicit host-switch path now supplies a silent external modulator and resets Ring's preparation state on each graph switch. The normal selected-only and prepared v2 slots keep the audible internal oscillator. The [C++ versus native Rust graph capture](checkpoint-88-ring-switch-metrics.json) and [C++ versus Wasm capture](checkpoint-88-ring-wasm-metrics.json) both report **2.24e-8** maximum difference over 32,768 stereo frames; the Ring segments match exactly at zero. A focused [design comparison plot](checkpoint-88-ring-choice.png) shows the old zero output beside the audible prepared v2 route, whose left peak reaches **0.0867** over the displayed window. [Numeric choice metrics](checkpoint-88-ring-choice-metrics.json) are checked in.

The [browser case](checkpoint-88-browser.png) offers Ring Mod as the seventh host-comparison type. It reports **Match**, explains why its old-graph output is flat, and points to the normal Standalone FX view for the internal oscillator. The live oscillator path remains running while Ring is selected. Fourteen of the 21 effect types still need graph preparation audits.

This comparison uses old C++ graph/runtime nodes wired according to the old Lua slot source; it does not execute the Lua binding or deferred graph worker. A future general graph importer must preserve the difference between an absent optional input and a connected silent bus.

Verification: `python scripts/probe-fx-ring-switch.py`, `node scripts/verify-fx-ring-wasm.mjs`, `python scripts/compare-fx-ring-choice.py`, 88 Rust tests, `cargo fmt --all --check`, `bash scripts/build-wasm.sh`, `npm run build --prefix web`, and Chromium comparison/live smoke test. Workbench totals: 45 views, 380 offline cases (236 C++ and 144 native Rust references).
