# Checkpoint 104 — manual Sine bank

Open the [Sine bank workbench](http://127.0.0.1:4173/?primitive=sine-bank). Start the instrument, edit the first eight harmonic amplitudes, expand partials 9–32, try the presets and drive shapes, then change unison, detune, and spread. The comparison drawer offers nine old C++ manual-mode captures, including the sync edge that the live editor does not yet route.

The [Rust kernel](../../crates/manifold-core/src/sine_bank.rs) keeps 32 partial slots and eight unison phase sets, with the original smoothing, phase wrap, voice fade, drive, pan, and normalization behavior. The [project](../../projects/sine-bank/project.json) routes the bank to stereo output. [Partial upload](../../crates/manifold-web/src/lib.rs) uses a fixed-size staging set, validates all active entries, and commits atomically between callbacks. The browser editor publishes amplitude changes through the AudioWorklet; no Lua runtime is involved.

The [C++ fixture manifest](../../web/public/reference/sine-bank/manifest.json) has nine stereo captures of 16,384 frames each, including a 64-frame empty case. The C++ runner compiles the original `SineBankNode.cpp`; its unused spectral collaborators abort if called, keeping this a manual-mode comparison. [Direct Wasm metrics](checkpoint-104-sine-bank-metrics.json) show a worst maximum absolute sample difference of 8.35e-7, in fold drive. The [AudioWorklet verifier](../../scripts/verify-sine-bank-worklet.mjs) passes the same nine cases at that bound and also checks audible initial output, centered mono, live upload, rejected upload preserving the previous sound, and stereo unison.
