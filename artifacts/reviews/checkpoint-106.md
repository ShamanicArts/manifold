# Checkpoint 106 — prepared Add and Morph targets

Open the [playable Sine bank](http://127.0.0.1:4173/?primitive=sine-bank): analyze the built-in tone or an audio file, choose Source frame, Add self, Add driven, or Morph, then select **Audition prepared target**. The source and resulting partial sets remain visible as compact level bars. Waveform, Morph amount, stretch, spectral tilt, temporal smoothing, and contrast are editable. The [recipe comparison page](http://127.0.0.1:4173/spectral-target-review.html) shows the original C++ and native Rust spectra slot by slot.

The [Rust preparation module](../../crates/manifold-core/src/spectral_targets.rs) ports the old waveform recipes, Add self and driven weighting, ratio normalization, shaping, and Morph amplitude/phase/frequency curves. [Temporal interpolation](../../crates/manifold-core/src/temporal_partials.rs) ports the old nearest-frame, smoothstep, neighbor smear, and contrast behavior. The [analysis worker](../../web/src/audio/sample-analysis-worker.js) retains one analyzed source in a dedicated Wasm instance, prepares targets off the audio callback, rejects stale source IDs, and transfers only a bounded target to the [AudioWorklet](../../web/src/audio/filter-processor.js). The audio callback still uses the fixed-capacity Sine bank and its validated block-boundary upload.

The [legacy recipe runner](../../tools/legacy-spectral-target-reference.cpp) compiles the original `SineBankNode.cpp`, `OscillatorNode.cpp`, and `TemporalPartialData.h` helpers from `my-plugin`. The [17 capture cases](../../web/public/reference/spectral-targets/manifest.json) cover eight waveform recipes, self and driven Add, three Morph positions, and four temporal interpolation situations. Across 108 ordered partial slots, the [comparison report](checkpoint-106-spectral-target-comparison.json) has worst frequency difference 1.9×10⁻⁵, level difference 4×10⁻⁸, phase difference 1.2×10⁻⁷, and decay difference 1.2×10⁻⁸. The larger frequency difference is in temporal neighbor smoothing and is still far below one cent.

The direct [worker probe](../../scripts/verify-temporal-worker.mjs) checks Add and Morph targets, typed-array transfer, source identity, and the earlier summary mode. The [worklet probe](../../scripts/verify-spectral-target-worklet.mjs) renders the prepared targets: Add RMS 0.203 and Morph RMS 0.148 in its inspected block, both finite and audible, with a changed waveform after upload. A headless Chromium interaction also prepared all three modes and started the live Morph instrument. The sample-region page still produced its old peak/RMS/pitch summary after the worker split.

Verification: 114 Rust workspace tests, legacy C++ capture regeneration, native Rust comparison, Wasm build, worker and worklet probes, Vite build, and served browser pages pass. The UI currently fixes wave recipe count to eight, drift to zero, pulse width to 50%, Morph depth to 0.7, and curve to equal power; the Rust preparation API supports the full fields. This checkpoint proves isolated prepared targets and their playback, not the old node's per-block sample playback pull, complete Add/Morph branch gain routing, phase vocoder, project state, or full Main sample synth parity. Those are next.
