Signal and state proof

The existing Rust MIDI Transpose tests check historical rounding, clamping, and note ownership. New native voice tests check raw versus quantized inputs, held-note retuning, the complete copied voice payload, and release by the source note. Direct Wasm measures a held C♯4 through Scale C4 → Transpose C5, then through raw C♯4 → C♯5: 670 versus 710 sounding crossings over equal windows. Chromium edits the original slider, connects both sources, observes the active voice mapping, saves and reopens version 12, imports version 11 disconnected defaults, and opens the direct link.

The prepared voice path is raw voice → optional Scale Quantizer → selectable Transpose input → synth. The audio callback performs no heap allocation. Main currently has one Transpose instance and this bounded source choice; arbitrary voice graphs and the remaining historical modules are still being ported.
