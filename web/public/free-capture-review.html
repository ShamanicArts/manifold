The automated browser run selected free mode, armed source 10, waited 220 ms, stopped, exported the project, checked the PCM frequency and actual frame count, then reopened the bundle. Native Rust’s existing wrap test checks 98→5 on a 100 frame ring as seven frames and equal offsets as one frame.
