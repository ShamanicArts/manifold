Manifold v2 / sidechain checkpoint / 27 September 2026

The capture bus is separate.

The graph now receives main and sidechain stereo inputs independently. A sidechain take can become the running sample instrument’s next-note source, while the main input keeps its own route to output.

The route

Main · 165 Hz test saw→Gain→Output sum
Sidechain · 330 Hz test triangle→Loop capture→Output sum
Stopped take→ publish →Sample instrument · new notes→Output sum

The Rust processor receives four planar channels: main left/right and sidechain left/right. `InputSidechain` reads only the second pair; when it is disconnected the node emits silence. The browser can connect a separate test oscillator or a microphone to the second AudioWorklet input.

The Rust graph test captures 0.75/−0.5 sidechain PCM while the main bus carries 0.25, then confirms silence when the sidechain is absent. A Wasm AudioWorklet test captures −0.5 from the second input even with 0.25 on the first. Chromium records the separate triangle oscillator, checks the embedded take’s zero-crossing frequency near 330 Hz, saves and reopens the project, and starts both buses again.

The sidechain graph path is ready for a future plug-in host’s second input bus. This checkpoint does not exercise a DAW sidechain or physical audio device timing. Selecting Microphone on both browser buses shares the same stream; independent physical device selection remains host work.
