The first rack cable changes the sound.

The authored Main default now compiles to a portable Rust graph: MIDI → Main voice bank → Filter → FX1 → FX2 → EQ → output. A second valid connection sends Source directly to FX1, bypassing the Filter. Both graphs ran through native Rust and the Rust/Wasm AudioWorklet with no speaker output.
