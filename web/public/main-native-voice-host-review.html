Scale Quantizer, Transpose, Note Filter, and Velocity Mapper now accept timed stable host IDs in the Rust Main processor. A native save carries those edits into the actual browser Main looper; the module faces below are screenshots from that reopened session.

The restored faces

One stable ID range per stage

StageHost IDsSaved fields
Scale Quantizer832–835Root, scale, direction, connection
Transpose864–866Semitones, source, connection
Note Filter896–900Low/high note, mode, source, connection
Velocity Mapper928–932Amount, curve, offset, source, connection

Every host value is validated before a block changes. A timed Note Filter edit preserves the first 64 audio frames and changes the voice after its exact offset. The audio thread freezes accepted values with loop and sample PCM; JSON is assembled on the control thread. Native tests reject fractional enum values and reimport the saved state. The muted browser probe opens and re-saves both the current and upgraded version-3 examples with identical PCM and the edited voice-stage controls.
