Proof and limits

Native Rust and the Wasm worklet rendered 8,192 stereo frames for Normal and Add modes with identical samples (maximum absolute difference 0). Chromium checked both fixed captures, live MIDI and parameter updates, save/reopen, standalone state import, and edited target persistence. The graph target contract rejects missing, duplicate, malformed, and out-of-range target data before replacing the open project.

A standalone state import transfers its current prepared targets and control values. It does not recreate the standalone view’s evolving temporal follow controller or preserve its target-control recipe. The comparison here is Rust versus Rust/Wasm; it does not claim a new C++/JUCE parity result for the full graph composition.
