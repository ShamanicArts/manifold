The first rack document can produce a prepared post-voice graph insert. A native Rust test installs it after Main's existing voice bank and before its real looper capture and monitor branches. The default route matches the fixed chain; a saved LFO cable changes the captured audio.

The CV insert changes output energy and the actual Main looper ring. The insert is built from the same portable Graph project format used by the native reader and Wasm build.

This is a DSP integration proof, not the finished Main Patch product.

The current Main browser page and Main CLAP/VST3 sessions still use their fixed chains. The test installs an insert with processing suspended. There is no live document publication, cable gesture, rack shell, dynamic layout, or cross-host saved rack state. The insert's Graph LFO also differs from Main's six-shape LFO, so their control and status models must be reconciled before exposing this route in the editor.
