The authored Standalone Sample export is a 472 × 220 shell with a graph, a blank panel, and an Audio Input/Sidechain dropdown. Its old DSP makes one dynamic sample slot with eight MIDI note voices. The new browser page uses those four authored widget bounds and routes the instrument through the Rust/Wasm graph. Device, capture, file, and keyboard controls live in a separate browser host area beneath the module.

Boundary and next work

The exported module's geometry and source selection are now represented, with live capture, file replacement, MIDI, loop flag dragging, and saved PCM running through Rust/Wasm. The dark shell palette and waveform drawing use shared Manifold widget conventions; exact rendered C++ pixels have not yet been compared. The old standalone UI itself authors no capture button, pitch mode, unison, or output slider, even though its borrowed Main rack behavior mentions them.

Graph CLAP and Graph VST3 accept this portable project and render it. A dedicated Standalone Sample plugin class/editor, legacy preset import, phase vocoder modes, transport quantization, and exact old DSP comparisons remain open. The current browser host performs seconds-based retrospective publication and does not claim full legacy feature parity.
