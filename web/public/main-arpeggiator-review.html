Signal and state proof

Native Rust tests compare 32 and 128 frame hosts: the first 240 samples at 8 kHz are silent, then the first chord step sounds at 30 ms, with identical rendered samples. The scheduler tests independent same-pitch output lanes, Hold, source amplitude, octave copies and gate close. The direct Wasm probe compares 32 and 128 frame output and confirms that Transpose C5/E5 enters the Arpeggiator, audible steps follow the capture window, and source note-off clears the route. Chromium verifies the original-size face, live held count and note, version 15 save/reopen, version 14 defaults, and the direct Main link.

The historical Lua module used a UI control clock; Main v2 schedules gate edges on the audio sample clock. This first route consumes the current connected Main voice stages. General graph wiring to arbitrary voice sources and multiple Arpeggiator instances remains to be ported.
