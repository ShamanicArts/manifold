Why stretch mode differs

The legacy C++ time read cursor advances once for each output channel. A stereo frame therefore reads the two channels at different moments and advances time twice. Rust advances the cursor once per frame. For the +7 st capture, the channel mismatch measure falls from 0.0449 RMS in C++ to 0.00000172 in Rust. The workbench marks those cases “Intentional change” and lets you hear and plot both outputs.
