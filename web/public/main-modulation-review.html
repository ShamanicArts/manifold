What came from the original

Main/ui/components/lfo.ui.lua defines the 236×220 module, graph and compact slider positions. Main/lib/lfo_runtime.lua defines the six shapes, bipolar/inverted/unipolar/end-of-cycle outputs, phase reset, and sync hold. Main/lib/modulation/route_compiler.lua supplies Add/Replace and typed endpoint rules. The v2 browser uses JavaScript controls and Canvas; Rust owns timing, route calculation, and sound.

This is one genuine LFO-to-Filter connection. The historical dynamic rack can add multiple modules and route to many other typed endpoints; that graph, patch cables, and live insertion/removal remain to port. Main CLAP/VST3 packaging and Link remain separate work.
