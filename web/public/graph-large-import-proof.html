The actual editor and host render

The browser project held 48 kHz stereo 440 Hz PCM, encoded in JSON. The editor transferred bounded chunks to the controller; the connected Rust processor validated and prepared the replacement before publishing it at a host block boundary.

The saved REAPER project rendered one second with MIDI note 60 from 0.125 to 0.5 seconds. All 48,000 stereo output frames match a direct native Rust render within 5.96e-8 peak sample error. This tests import, recall, and the first second of playback; it does not measure playback through the entire 30-second source.

Two independent sources in one saved graph

A second sample instrument carries its own 10-second 660 Hz stereo source. The original 440 Hz source feeds an SVF filter; both instrument outputs meet at the graph's audio sum. This 10,241,747-byte project has seven nodes and 31 bound controls. REAPER saved it and reopened it in a fresh process; its full one-second render matched direct native Rust within 5.96e-8 peak sample error.

Muting only the second source changes the direct Rust render by 0.0214 RMS, so the matching host audio includes both assets. The imported 10-second sources were checked through the first second of playback.
