The authored graph

Live input feeds Retrospective capture 6 as a silent processing root. MIDI feeds Sample instrument 5 and then Output. The capture branch stays active even though it has no audible route. That is deliberate: a smoothed zero-gain node briefly leaked input at startup, so the compiler now gives retrospective capture its own processing root.

The Rust ring supports 1–120 seconds; this project fixes its capacity at the original 30-second default. A requested window is separate from capacity. Before the ring has enough history, the selected window begins with silence, matching the old cleared capture buffer.

Verified: Rust early-history and reset behavior, native project preparation, Wasm window capture and new-note audio, and Chromium capture/save/reopen. The direct Wasm test also proves that the input remains inaudible before a note is played.

What remains

This is a port of the retrospective source primitive and one playable sampler graph, not the whole old Standalone Sample. The original project selects among multiple sources, applies a source gain of four, maps transport bars and free-capture offsets to samples, updates per-voice sample playback, and offers further pitch and analysis modes. Those contracts need separate parity probes. Publication remains an explicit user action and physical-device underruns are still unmeasured.
