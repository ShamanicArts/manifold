Signal and state proof

The historical Lua Range tests pass. Native Rust tests cover Clamp, Remap, reversed limits, and a CV Mix input reaching an FX route. Direct Wasm changes FX1 mix from 0.45 to 0.70 through CV Mix → Range; equal-window held-note energy changes from 21.12 to 11.51. Chromium edits the face, connects CV Mix OUT, selects Range OUT in a route, saves and reopens version 10, imports version 9 with defaults, and verifies the direct module link.

The prepared control order is LFO → ATV → Slew → Sample Hold → Compare → CV Mix → Range → routes. The callback has no allocation or graph compilation. Main currently has one Range instance and the existing Filter/FX route endpoints; arbitrary patch graphs, multiple utility instances, and the rest of the historical Main rack are still being ported.
