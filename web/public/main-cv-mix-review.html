Signal and state proof

The legacy Lua CV Mix tests pass. Native Rust verifies four distinct typed inputs, weighted sum, offset, OUT/INV polarity, and FX1 route values. Direct Wasm measures CV Mix OUT +0.50 and INV −0.50 changing FX1 mix from 0.75 to 0.25; equal-window held-note energy changes from 9.59 to 28.81. Chromium edits all five original sliders, patches four sources, selects the live route, saves and reopens version 9, imports version 8 defaults, and checks the direct module link.

The prepared frame processes LFO → ATV → Slew → Sample Hold → Compare → CV Mix → routes without allocation in the callback. One CV Mix instance and the current Filter/FX endpoints are available; arbitrary patch graphs and multiple utility instances remain open.
