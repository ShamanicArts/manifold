The ownership boundary

Host owns native processor exclusively→Begin staged ring snapshot→Audio blocks finish bounded copy→Control thread exports PCM and prepares graph→Replacement ready for block-boundary publication

Allocating and encoding the portable PCM asset happen in the synchronized control transaction. The audio process function only advances the staged copy and continues rendering. The existing VST3 and CLAP tests separately prove that both plug-in adapters can reopen and play a browser-exported take.

Verified: native stage begin/status/copy, sidechain isolation and gain, 9,600-frame length, embedded state, MIDI output, and save/reopen. The full Rust workspace suite passes.
