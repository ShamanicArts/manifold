Original controls, saved ports

Changing the Slew input selector to ATV / Bias OUT replaces its saved input wire. Dragging Slew onto LFO 1’s occupied cell inserts it before LFO and ATV; both displaced shells move during the drag, and the saved session reopens in that layout.

What was checked

Browser and Wasm

Muted Chromium connected Slew OUT, received the Rust AudioWorklet route acknowledgement, saved, unplugged, reopened, switched the input selector, and saved again. Pointer dragging reflowed the row; reopen retained the new cells and cables.

Native signal

The browser session prepared in native Main. A sounding note changed by more than 10% in measured energy when its Slew route was enabled. Native loading rejected a mismatched Slew input selector.

Shared contract

The authored rack catalog now describes the supported LFO, ATV, and Slew control edges. Browser and native validation use those bindings; native export reconciles input and output cables after host parameter changes.

Current boundary

This is a prepared control chain, with LFO 1 OUT or ATV OUT feeding Slew IN and Slew OUT reaching Filter CUTOFF through slot zero. Other Slew inputs and destinations still use the separate route controls. The packaged native editor displays control cables read only.
