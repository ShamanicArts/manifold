What the measurements cover

Two fixed 8,192-frame stereo cases render with 128-frame process blocks and a 2,048-frame prepared capacity, matching the AudioWorklet. File-source native/Wasm output differs by at most 0.000000060 per sample; live capture differs by at most 0.000000030. Chromium verifies worklet start, live Density updates, file project reopen, source removal, an external input route, and a source-free project download.

The granulator ring includes prepared block capacity in its size. A native comparison prepared for a different capacity reads a different ring position even when it processes 128-frame blocks. The study uses Position 0.01 and Spray 0 so live capture reads behind the write head and produces audio promptly. These are Rust versus Rust/Wasm graph comparisons; C++/JUCE parity for this composition is not claimed.
