What this exposed

REAPER supplies the discrete effect selector as a widened 32-bit float. Its normalized Reverb value is approximately 0.349999994, not an exact 0.35. The editor previously sent that imprecision into the browser project parser as a fractional effect index. The controller now quantizes the selector to one of 21 positions, and editor snapshots serialize its project value as an integer. The repeatable probe catches this host-specific failure.

This proves host loading, visible host edits, widget gestures, project recall, automation recording and replay, two simultaneous instances, and editor close/reopen in REAPER. Varied bus configurations and Windows/macOS hosts are subsequent gates.

Repeat locally with a disposable Xvfb/XTEST display: DISPLAY=:88 MANIFOLD_ISOLATED_DISPLAY=1 python3 scripts/probe-reaper-vst3.py. The script uses a temporary REAPER configuration and project and closes its isolated host process.
