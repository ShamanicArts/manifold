Silence peak and retrigger error are both 0.0. The Rust CLAP test also checks that a timed host automation value survives reset and subsequent state save. External probe data · Validator results.

Large asset timing

The 44,742,408-byte four-source project was prepared once. Each of 512 measured iterations rendered eight notes into its native graph, then reset without replacing its graph or PCM. Reset median was 0.00017 ms, p95 0.00020 ms, and maximum 0.00051 ms on this machine. These are offline native timings; they do not measure DAW scheduling or physical device underruns. Timing data.
