Why the first comparison differed

A 512-frame native reference differs from REAPER by up to 0.0164 during startup; the 1,024-frame reference matches the entire wet render to 5.96e-08. The original C++ WaveShaper advances one shared smoothing state through the left channel before the right. Rust preserves that behavior, so its startup response depends on block partition. This plot shows the 512-frame comparison over the first 4,096 frames.

This comparison covers WaveShaper at 48 kHz in one REAPER render configuration. The full wet and bypass renders match their 1,024-frame native references to 24-bit WAV quantization. Other effect types and host buffer layouts require their own comparisons. Preserving the legacy channel-first smoothing is a deliberate porting decision that can be revisited.
