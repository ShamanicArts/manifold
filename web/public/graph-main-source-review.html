A new source gets a new spectrum.

Replacing a Main bank file in the editable graph now analyzes that file in the background Rust/Wasm worker. The editor commits its stereo PCM and prepared source target together, while preserving the authored wave target.

The handoff

Decoded stereo file→Rust/Wasm source analysis worker→Source partial target
PCM + source target→ atomic editor updatePrepared Rust Main bank→Output

Analysis happens outside the audio callback. A failed or silent analysis leaves the previous file and both targets intact. Wave partials are independent of the sample and stay as the user authored them.

Verification and scope

Chromium loaded a pitched stereo WAV, verified a changed source target and unchanged wave target in the downloaded project, then started the Rust/Wasm instrument. A second WAV with opposite-polarity channels yielded no usable partials; the browser verified the source PCM and both targets were preserved. The 11 fixed graph reference captures still compare native Rust with Wasm.

This uses the standalone Main editor’s default source target recipe. The graph does not yet expose its full spectral shaping recipe or per-voice temporal follow behavior.
