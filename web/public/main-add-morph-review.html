Try it

1 · Start the instrument

Open the Main voice bank and start audio. Use the on-screen keyboard to hold a chord. Select Add or Morph in Blend mode and move Direction depth toward 1.

2 · Change the source spectrum

Load a short audio file or use the built-in source. In Source analysis, choose a frame and audition the prepared target. The worker prepares the wave recipe and source partials in Rust/Wasm, then uploads them between audio blocks.

The route

sample → raw envelope follower → phrase contour
wave recipe + source partials → Add crossfade / Morph source → depth mix with base wave/sample → ADSR → stereo sum

Add follows the Wave / sample position. Morph selects the source spectrum and moves its pitch between wave and sample targets. Each voice keeps its own oscillator phase and phrase state; both target sets are shared as values across voices.

Evidence and limits
