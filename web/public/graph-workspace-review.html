What was measured

The sample voice route renders 8,192 stereo frames at 48 kHz with timed note on and off events. Its native Rust capture and direct Wasm render match sample for sample. The browser check starts the worklet, loads a replacement WAV, stores two distinct node assets, plays with a parked node, connects both routes, and reopens an embedded sample project.

The comparison is native Rust versus Rust/Wasm; it does not claim a C++/JUCE sample instrument match. This checkpoint uses browser file decoding and embeds at most four assets with a 32 MiB PCM budget. Graph edits compile on the next start.
