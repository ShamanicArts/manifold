How to try it

01 / Edit

Shape the route

Add Distortion, connect Gain to its Audio input, then connect Distortion to Output. Parameter fields set the graph’s initial sound.

02 / Compile

Start audio

The worklet passes the authored description into Rust/Wasm. The Rust graph compiler checks node types, ports, reachability, and cycles.

03 / Compare

See the samples

Below the workbench, select seed, distortion, or CV. The viewer compares fixed native Rust captures to a direct Wasm render.

04 / Keep

Save topology

Stop audio, download the versioned graph project JSON, remove a node, then open the file to restore it.

What is proven

Each reference renders 8,192 stereo frames at 48 kHz in 128-frame blocks. The seed is bit-exact; distortion and CV gain each differ by at most 0.000000060 per sample between native Rust and the actual Wasm worklet. Browser checks also cover typed selector choices, cycle rejection, blocked edits while running, and project save/reopen. Invalid imported routes leave the open graph unchanged.

Topology changes compile on the next start and reset node state. The older CV rack supports live rerouting among prepared nodes. This editor does not yet replace a running graph, migrate node state, import a Lua project, or package a native plug-in.
