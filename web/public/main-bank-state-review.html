What travels with the bundle

Authored graph and controls

The fixed signal graph identifies the Main bank route. The snapshot holds its 20 controls: waveform, blend, depth, pitch, Ring, FM/Sync, ADSR, phrase, master, and vocoder.

Prepared sound

Separate wave and source partial arrays carry exact frequencies, levels, phase, and decay. Opening does not replace them with a fresh analysis result.

Source audio

The built-in source is saved by choice; a user file is embedded as bounded stereo float32 PCM with its sample rate and label.

Try the round trip

  1. Open the Main bank workbench and find Main voice bank project.
  2. Change a control, then choose Download project bundle.
  3. Stop audio, choose Open project bundle or older state, and select the downloaded JSON. Restart audio and play the keyboard.
  4. For compatibility, open the older example state with the same control.

The source is limited to 30 seconds and imports to 20 MB. The bundle carries the authored graph, but graph editing and replacement are not implemented: a graph that differs from this view is rejected. Background source analysis only updates the editor until you audition a new target. The original JUCE/Lua project and preset library have not been migrated.

Verification

The bundle round-trips all 20 bank controls, both target arrays, source audio, temporal follow and speed, and the spectral recipe. The project reader accepts older bare state files and rejects a changed graph or invalid snapshot before replacing the session. Browser workflows reopen Add and Morph bundles and restart the AudioWorklet.
