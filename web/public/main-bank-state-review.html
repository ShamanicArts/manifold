What travels with the state

Playing behavior

Waveform, blend mode, depth, pitch mapping, Ring direction, FM/Sync, ADSR, phrase contour, master, and vocoder controls.

Prepared sound

Separate wave and source partial arrays with their exact frequencies, levels, phase, and decay. Opening does not replace them with a fresh analysis result.

Source audio

The built-in source is saved by choice; a user file is embedded as bounded stereo float32 PCM with its sample rate and label.

Try the round trip

  1. Download the example state.
  2. Open the Main bank workbench and find Main voice bank state.
  3. Choose Open project state, select the JSON, then start audio and play the on-screen keyboard.
  4. Change controls or select a source file; Download project state saves the new session. Stop audio before opening a different state.

The saved source is limited to 30 seconds and the state file to 20 MB on import. Opening restores the prepared targets first; background source analysis only updates the editor until you explicitly audition a new target. This is state for the authored v2 Main bank, not a migration of the original JUCE/Lua project or its preset library.

Verification

The state round-trips all 20 bank controls, both target arrays, embedded PCM, temporal follow and speed, and the spectral recipe: pulse width, Morph amount, depth and curve, stretch and tilt. A browser workflow reopened Add and Morph states, rebuilt raw temporal frames from the saved source, and started the AudioWorklet without a page error. Earlier version-3 files receive the previous recipe defaults. Malformed targets, control values, and source data are rejected before replacing the current session.
