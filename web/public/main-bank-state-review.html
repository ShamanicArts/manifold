A Main bank project can hold presets.

The eight-voice instrument downloads a versioned bundle containing its authored signal graph, validated current sound, and named presets. Presets keep controls and prepared targets while sharing the project sample, so audio is embedded only once.

What travels with the bundle

Authored graph and controls

The fixed graph identifies the Main bank route. The current snapshot holds 20 controls: waveform, blend, depth, pitch, Ring, FM/Sync, ADSR, phrase, master, and vocoder.

Named sounds

Up to 32 presets hold their own controls and, for the bank, both prepared partial targets. Each preset uses the project's current source audio when applied.

Shared source

The built-in source is saved by choice; a user file is embedded as bounded stereo float32 PCM with its sample rate and label. Presets do not duplicate it.

Try the round trip

  1. Open the Main bank workbench and find Main voice bank project.
  2. Change the sound, enter a preset name, and choose Store. Change controls again, stop audio, then choose Apply to recall it.
  3. Choose Download project bundle. Reopen the downloaded JSON using Open project bundle or older state and select the named preset.
  4. For compatibility, open the older example state with the same control.

Download after storing or removing a preset to keep that change. The source is limited to 30 seconds and imports to 20 MB. Graph replacement remains unavailable: a graph different from this view is rejected. This is a v2 sound preset model; it is not a migration of the original JUCE/Lua runtime state, rack layout, or preset library.

Verification

The bundle round-trips all 20 bank controls, two target arrays, source audio, temporal follow and speed, and named presets. Browser checks store and apply a bank preset, save and reopen a blend preset, remove it, reject a changed graph, and open an older bare state. Add and Morph bundles still restart the AudioWorklet.
