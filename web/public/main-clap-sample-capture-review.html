The Main Sample controls
now reach native audio.

The existing Source widget keeps its Live and L1–L4 sources, Retro and Free modes, Bars control, and Cap/STOP action. The packaged CLAP editor sends those gestures to the Rust Main engine. The audio callback freezes source PCM in prepared storage; a bounded mailbox moves it to the control thread for validation before the sample bank changes.

What is proven

BoundaryObserved result
Original widget → CLAPAn isolated packaged-host probe clicks the original Source Cap in the child webview, drives in-memory audio blocks, observes native publication, and saves a 96,000-frame Sample. A CLAP IPC test independently checks a 6,000-frame Retro Live request; the muted browser probe checks Retro and Free actions and progress repaint.
Prepared audio transferFive preallocated capture rings retain dry Live and gated L1–L4 playback. The core freezes at most 4,096 stereo frames per host block, including blocks split by timed automation. Two prepared transfer chunks provide backpressure while the control thread assembles and validates PCM. The audio callback swaps a prepared shared source and retires the displaced PCM to the control thread.
Retro and Free behaviorA native signal test captures 1,000 recent Retro Live frames at 0.4 amplitude, then a separate 640-frame Free Live take at 0.7. A new MIDI note plays the Free sample while Main's looper runtime stays in place.
Portable state and cancellationThe same test saves the running Main session and reopens the 640-frame Sample with its peak unchanged. An accepted replacement session or editor close cancels a waiting capture; the audio owner releases it and accepts the next gesture.
Release build correctionThe packaged probe exposed queue writes inside debug assertions. Those writes disappeared in the optimized CLAP build. They now execute unconditionally; the release-host click-through publishes and saves the Sample.
Remaining host gateA real DAW click-through and real-device callback timing remain open. Session file actions are still disabled in the embedded editor, and Main VST3 has not yet been added.
