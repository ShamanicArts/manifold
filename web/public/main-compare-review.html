Signal and state proof

The legacy Lua Compare tests pass. Native Rust tests cover threshold crossings, hysteresis, Rising/Falling/Both, the two-tick trigger, input validation, and a Main FX1 route. In direct Wasm, Compare GATE moves FX1 mix from 0 to 1; equal-window held-note energy changes from 38.42 to 0.57. Both-edge TRIG remains high for two processing ticks. Chromium changes the original controls, routes Compare, saves and reopens version 8 including gate and pulse state, imports version 7 defaults, and opens the direct module link.

The prepared chain is LFO → ATV → Slew → Sample Hold → Compare → routes. Compare currently updates once per audio block. Its two-tick pulse is therefore two blocks rather than two of the old Lua UI control ticks. Fast within-block crossings and the wider arbitrary patch graph remain open.
