Architecture that is holding up

Rust owns DSP and audio state. The browser AudioWorklet and native host adapters only bridge devices, timed events and bounded control messages. JavaScript owns the workbench; its visual renderer reads analysis and never sets audio timing. Capture buffers, graph memory and resources are prepared before callbacks. Legacy JUCE/Lua remains the behavior and design reference; there is no Lua runtime in v2.

The strongest evidence is local behavior parity and end-to-end browser/REAPER paths. It does not yet prove every old Manifold project, broad host compatibility, physical-device underrun safety, or macOS/Windows packaging.
