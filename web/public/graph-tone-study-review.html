Evidence and boundary

The authored eight-node document contains six typed edges and explicit internal-source mode. A native Rust graph and the Wasm AudioWorklet produced identical samples for 8,192 stereo frames at 48 kHz in 128-frame blocks. The browser check loaded the study, started without an external source, changed oscillator frequency from 220 to 330 Hz during playback, downloaded the project, and reopened it with the frequency and source mode intact. Earlier graph documents without a source-mode field still open as external-input projects.

This is a sustained sound study. It does not yet map MIDI notes or envelopes into the editable graph, carry sample assets, replace a running plan, or reconstruct the full old Main project. The offline capture is the fixed starting sound; later live edits do not rewrite its reference file.
