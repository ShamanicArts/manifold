What the round trip exercised

1 · Browser state inA version-15 Main session starts with a 6,000-frame stereo loop and Main Sample.
2 · Native editsTimed host actions change Source and FX controls inside Rust processing.
3 · Bounded saveThe audio thread freezes controls and copies PCM in prepared chunks; the control thread writes JSON.
4 · Browser state outMain opens the native file, plays its loop, and re-saves identical PCM with the edited rack values.

Proof and next boundary

The native reimport test checks PCM, changed controls, inactive FX memories, EQ, and Arpeggiator state. The browser probe checks the real page, the loaded loop and sample, and byte-identical PCM after a second save. Reproduce with cargo run -p manifold-native --example export_main_browser_session -- web/public/main-native-saved-session.json and node scripts/verify-main-native-session-browser.mjs.

A fresh native Main instance now starts from the browser-authored default version-15 session and can save immediately. The native test reopens that save and compares note audio sample by sample. Older version 1–14 imports still need promotion before saving; Main CLAP/VST3 state callbacks are next.
