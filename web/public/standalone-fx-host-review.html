From browser to a loadable plug-in.

The Standalone FX project now opens in the browser and in a native CLAP host. Both paths run the Rust persistent effect graph. The browser draws the ported widget controls; CLAP exposes the seven host parameters and project state through a loadable plug-in.

What the host proof exercises

BoundaryEvidence
Project loadThe exact standalone-fx-module/project.json is validated and prepared by manifold-native.
AudioCLAP stereo f32 input and output enter preallocated host buffers. An ABI host test compares its 128-frame output sample for sample with the native project renderer.
AutomationCLAP parameter events map to fixed host slots and reach the Rust graph at their frame offsets. Switching effect type now restores that effect's five remembered controls in both DSP and host-visible parameter values; the host is asked to rescan those values on its main thread.
StateHost stream callbacks save and reopen the authored project JSON with all 21 effects' remembered controls. The browser can export and reopen that same host project file.
Independent validatorCLAP validator v0.4.1 loaded the built .clap file and passed in-place audio, varied blocks and rates, parameter, and state tests.

Still to connect

The CLAP module currently uses the host's generic parameter editor. The browser widget surface is not embedded in a DAW yet. A proper allocation-free DSP reset and VST3/Audio Unit adapters are next host milestones. Visual pixel parity against the running old JUCE/ImGui export is still unmeasured.
