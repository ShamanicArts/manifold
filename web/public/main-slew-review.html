Signal proof

Native tests compare the Lua rise/fall formula, including Linear, Log and Exp shapes. At 8 kHz with 128-frame blocks, a 1,000 ms Linear rise from ATV +1 produces Slew OUT 0.016 after one block and 0.983 after further blocks. A direct Wasm route through FX1 mix changes equal-window held-note energy from 6.13 to 0.65. Chromium starts the same Rust/Wasm instrument, changes the original controls, saves version 6 with Slew state, reopens it, and imports version 5 with default Slew state.

The rack currently prepares one Slew instance and one route per active LFO. Control updates use audio block elapsed time; the old Lua UI control tick can use a different cadence.
