A quieter final
sample switch

Publishing a captured sample used to copy the whole frozen PCM window in one AudioWorklet message. The browser now fills a prepared destination across render blocks and moves it into the instrument when complete. The original instrument’s held notes keep their source.

The transaction

1 · FreezeThe running graph fixes a recent source window in its staging buffer.
2 · ExportThe main thread receives PCM chunks to assemble the portable project asset.
3 · PrepareAfter each audio block, Rust copies up to 2,048 frames into a reserved destination.
4 · PublishA final message moves that vector into the instrument. Held notes retain their earlier PCM.
