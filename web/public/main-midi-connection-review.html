Connect a MIDI input on the Main page.

The new Hardware MIDI bar sits above the Main instrument. Permission is requested only when you press Connect MIDI; after access is granted, choose one of the available input devices.

Where to connect

1 · Start audio

Press Start audio. You can leave Dry input at None to play only the synth.

2 · Connect MIDI

Press Connect MIDI and grant the browser permission. The input menu lists connected devices.

3 · Play

Select a device and play notes. The status shows incoming note and channel. Note off and sustain pedal release are tracked; Disconnect MIDI releases held notes.

A muted browser run used two simulated MIDI devices. It confirmed an explicit permission request, device selection, note on/off messages reaching the Main AudioWorklet, disconnection, and zero page errors.

Browser permission still applies.

The embedded BB browser may block Web MIDI permission. In that view the Main page explains the restriction and offers a copyable link for a browser that supports Web MIDI. A physical device has not yet been tested here. Browser MIDI currently enters Main at the next audio block; precise timestamp scheduling and pitch bend through the Main instrument remain open.
