The path

01 / Capture

Record and stop

The Rust loop owns a two-second stereo ring. Export is available after recording stops while audio remains running.

02 / Transfer

Copy the take

The worklet exports bounded chunks. Browser state holds the PCM while the loop graph stops and the Main view opens.

03 / Prepare

Analyze off callback

The sample analysis worker extracts temporal frames. Audition prepares Add/Morph partial targets for the new source.

04 / Keep

Save the project

The bundle embeds stereo PCM once, alongside the fixed graph, current controls, targets, and any named sound presets.

Try it

  1. Open Loop capture, start audio with the test oscillator, and turn Record on then off.
  2. Choose Send take to Main voice bank or Send take to Main blend. Wait for the source analysis.
  3. Choose Audition prepared target. In the bank, start the instrument and play the on-screen keyboard.
  4. Choose Download project bundle; stop audio before reopening it.

The test oscillator is a reproducible input for this browser check. Microphone capture uses the existing browser permission flow. A take shorter than 256 frames cannot become a saved Main source. Full old Main looper and rack routing are still outside this slice.

Observed browser run

One headless Chromium run recorded 23,552 frames for the bank and 24,576 for the blend at 48 kHz. Both takes had a 0.157 absolute peak, produced prepared spectral targets, and reopened from their downloaded project bundles. The bank also played a note through the AudioWorklet. A previously auditioned bank target reset to the authored starting targets when the new take arrived. The check found no page errors. Exact take length varies with browser scheduling.
