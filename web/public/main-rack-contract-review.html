Next boundary

These document edits are not yet live audio edits. Main’s Rust instrument and browser still use the existing fixed chain and selector routes. The next proof must compile connections into the audio path, publish changes between blocks, and carry the same state through browser and native sessions. Only then can cable gestures appear as a working Patch mode.
