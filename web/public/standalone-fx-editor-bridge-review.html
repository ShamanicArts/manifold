MANIFOLD / EDITOR BRIDGEOpen live editor mode ↗

The same widgets inside an editor-sized surface.

The Standalone FX browser module now has a 500 × 246 editor mode. It mounts the same authored ui.json, Canvas compact sliders, dropdown, XY pad, and filter graph as the full browser page. The preview receives host project state and emits versioned parameter messages through window.ipc.

What is proven

Widget identity
The editor mode and browser module execute the same project-ui.js widget renderer. No HTML range control replaces the ported compact slider.
Host input
A host project JSON snapshot restores the selected effect and all remembered controls in the editor surface.
Host output
Moving a slider produces versioned begin, value, and end messages with a stable public parameter ID. The browser test captures their order; a CLAP host test checks their output event forms and retry behavior.
Audio boundary
Editor mode does not start a browser audio context. The loadable CLAP module continues to process audio through native Rust.

Next connection

This is a browser preview of the editor bridge. The CLAP module does not yet expose the GUI extension or embed the page in a DAW. The companion WebKitGTK process, real IPC receiver, and X11 lifecycle remain to implement and validate.
