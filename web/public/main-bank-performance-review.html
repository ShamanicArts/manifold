What this tells us

Polyphony cost

Normal mode rises with active voice count. Ring, FM, and Sync stay near the eight-voice Normal range in this harness. Add/Morph and vocoder are the more expensive routes.

Morph’s unused bank

The old Morph route disables its Add wave oscillator. The Rust bank now avoids rendering its wave spectrum in Morph mode and keeps only the source spectrum active. All ten native/Wasm bank captures still pass.

This is a local Node/V8 proxy, not a measured browser AudioWorklet on the user’s audio device. The harness includes JS buffer copies, event dispatch, and Rust/Wasm processing, but excludes setup and asset uploads. Unchanged Wasm linear memory during measured blocks does not prove zero transient allocation. Browser thread timing and device underruns remain to be measured.
