The graph validates every field before saving. An edited recipe is analyzed in the background on the next start, then installed before the AudioWorklet reports ready. Speed remains a separate live control.

The panel uses web controls inspired by the old compact widget language. The Lua runtime is not part of this browser or Rust audio path.
