What remains

This is a real, narrow CV path through the separate Graph host. The live Main looper instrument still uses its fixed assembled chain, and its Rack/Patch face does not yet edit this graph. The current graph LFO supports three shapes and this Cutoff connection uses a 2,000 Hz bipolar depth. The legacy module has six shapes plus phase, depth, reset, sync and more ports. Their behavior and exact modulation mapping still need porting and comparison.
