More than one LFO
in the instrument.

The Main page can now add and remove prepared LFO modules while audio runs. Each visible module uses the original LFO component geometry and compact sliders; each has separate Rust timing, output ports and one typed control route.

The added module

Chromium close-ups after adding LFO 2. The LFO face follows the legacy 236×220 component. The route editor is a v2 control surface for the typed connection.

Use MidiSynth → PATCH ↓ → + LFO, then scroll down in the rack. Choose an output and a Filter or FX mix target. The × button removes the added module and its route. The first LFO remains the rack’s base module.

What the engine proves

Two independent sourcesThe first LFO changes Filter cutoff. The second changes FX1 mix without moving the first route.
Audible FX routeDirect Wasm: FX1 mix 1.00 → 0.00; matched note-window energy 0.23 → 19.22.
Session reopenVersion 4 saves occupied slots and routes. Chromium reopens both modules and still imports versions 1–3.

Rust prepares four slots before audio starts. Each slot has one route. Routes targeting the same control apply in slot order: Add composes with the current value, and a later Replace takes precedence. The existing base control returns when the route is removed.
