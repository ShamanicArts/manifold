Source module checkpoint: Wave, Sample, Blend

The Source module now uses the original 560-pixel panel geometry: graph on the left, Wave/Sample/Blend tabs on the right, segmented Wave/Sample/Blend selectors, and compact slider controls from Manifold’s Lua widget renderer. Live taps dry input. L1–L4 tap each loop after its playback gate and before volume gain. Retro or Free Cap publishes a validated stereo sample to the Rust eight-voice bank. The graph reads bounded peaks from that actual sample; Wave and Blend controls target the Rust oscillator and blend modes.

Free Sample recording

Free mode uses two presses of the original Cap control. The first marks the selected source and shows STOP with an elapsed-length readout; the second captures only the audio recorded since that press. The Rust capture keeps the original source even if selection changes, and caps long recordings to the prepared ring.

L1 Free recording in Chromium with the elapsed duration visible.
The second press published the L1 span to the Rust voice bank. Direct Wasm playback and native timing tests cover the signal path.

What is connected

First LoopREC measures the selected layer’s input span. Stop infers legal bars and BPM nearest the Target value, then commits audio to that layer.
Retrospective captureAll four layers keep 30 seconds of input. The nine bar regions select recent history without a preceding REC action.
Four playable layersIndependent loop PCM, position, volume, mute, signed speed/reverse, seek/scrub, play/pause, and clear. Dry input and loop output mix as in Main.
Other modes and persistenceFree Mode quantizes at the current tempo. Traditional arms a segment for explicit fire. Both commit-based overdub length policies are in Rust. Session JSON saves four loops and controls for same-rate reopen.

Try the connected path

  1. Open the live port with Dry input set to None and start audio. Hold a piano key, then release it.
  2. Click the 1/16 segment to make a retrospective loop from that note. Select another layer and repeat with a different note.
  3. Select Test tone before starting audio again. Press REC for roughly one second, then press it again. First Loop infers BPM near Target and fills the active layer.
  4. Select another layer, click 1/4, and hear recent input loop beside the first layer. Traditional mode arms a segment for the separate Commit armed action.
  5. Download a session, restart audio, then open the file at the same sample rate. Waveform scrubbing, signed speed, mute, and per-layer play controls are available.

Proof and boundary

The Rust workspace tests pass, including dry-only Live sample capture, playback and chronological Sample graph peak probes. Direct Wasm checks verify First Loop timing, a dry-input retrospective commit, a Rust Main voice note saved into another layer, and Retro/Free Sample capture and playback. Chromium exercises First Loop, capture, Live/L1 Retro Cap and L1 Free Cap/STOP, the visible Sample waveform and Wave/Sample/Blend tabs, Traditional arm/fire, scrubbing, saved-session reopen, decoded file input, and the voice source. The four 30-second prepared capture and loop buffers use about 132 MiB at 48 kHz before voice bank memory.

Still missing from the historical Main instrument: the full MidiSynth rack interface, effects and modulation path; Ableton Link and host transport; legacy preset import; and native packaging of this Main looper. The page’s piano keys expose the ported voice bank for testing. They are not a substitute for Lucas’s original MidiSynth surface. Session imports require the same sample rate and publish layers one at a time.
