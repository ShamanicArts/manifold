What is connected

First LoopREC measures the selected layer’s input span. Stop infers legal bars and BPM nearest the Target value, then commits audio to that layer.
Retrospective captureAll four layers keep 30 seconds of input. The nine bar regions select recent history without a preceding REC action.
Four playable layersIndependent loop PCM, position, volume, mute, signed speed/reverse, seek/scrub, play/pause, and clear. Dry input and loop output mix as in Main.
Other modes and persistenceFree Mode quantizes at the current tempo. Traditional arms a segment for explicit fire. Both commit-based overdub length policies are in Rust. Session JSON saves four loops and controls for same-rate reopen.

Try the instrument

  1. Open the looper, leave Test tone selected, and press Start audio. Change Tone Hz to hear the input change.
  2. Press REC for roughly one second, then press it again. First Loop should set BPM near Target and fill L0.
  3. Select L1 via its donut or strip. Click 1/4 on the capture plane. L1 should play the last quarter bar while L0 continues.
  4. Choose Traditional and click 1/8; the region arms. Press Commit armed segment. Drag a layer waveform left or right to scrub.
  5. Download a session, stop and restart audio, then open that file. The saved loops and controls return at the same device rate.
  6. Choose Microphone to grant browser audio permission, or choose an audio file as a looping source.

Proof and boundary

The full Rust workspace passed 230 tests. A direct Wasm signal check passed First Loop tempo/audio and a second-layer retrospective output. Chromium exercised the page, Traditional arm/fire, waveform scrub, decoded audio file input, and session save/reopen. A synthetic Node run at 48 kHz with four loops measured 128-frame processing at 0.015 ms p95 and 0.687 ms maximum; a full presentation peak poll measured 0.611 ms p95 against a 2.667 ms block period. These timings are synthetic and do not establish physical-device underrun safety.

The four prepared 30-second capture and loop buffers use about 132 MiB at 48 kHz. Commits copy at most 4,096 frames per audio block, so a long loop becomes audible after bounded preparation. Sessions reopen at the same sample rate and publish imported layers one at a time. Main’s MidiSynth-to-looper routing, Ableton Link, legacy preset import, and native looper CLAP/VST3 packaging remain open.
