What is connected

First LoopREC measures the selected layer’s input span. Stop infers legal bars and BPM nearest the Target value, then commits audio to that layer.
Retrospective captureAll four layers keep 30 seconds of input. The nine bar regions select recent history without a preceding REC action.
Four playable layersIndependent loop PCM, position, volume, mute, signed speed/reverse, seek/scrub, play/pause, and clear. Dry input and loop output mix as in Main.
Other modes and persistenceFree Mode quantizes at the current tempo. Traditional arms a segment for explicit fire. Both commit-based overdub length policies are in Rust. Session JSON saves four loops and controls for same-rate reopen.

Try the connected path

  1. Open the live port with Dry input set to None and start audio. Hold a piano key, then release it.
  2. Click the 1/16 segment to make a retrospective loop from that note. Select another layer and repeat with a different note.
  3. Select Test tone before starting audio again. Press REC for roughly one second, then press it again. First Loop infers BPM near Target and fills the active layer.
  4. Select another layer, click 1/4, and hear recent input loop beside the first layer. Traditional mode arms a segment for the separate Commit armed action.
  5. Download a session, restart audio, then open the file at the same sample rate. Waveform scrubbing, signed speed, mute, and per-layer play controls are available.

Proof and boundary

The Rust workspace tests pass, including a dry-only Live sample capture and playback probe. Direct Wasm checks verify First Loop timing, a dry-input retrospective commit, a Rust Main voice note saved into another layer, and Live Sample capture and playback. Chromium exercises First Loop, capture, Live Sample Cap, Traditional arm/fire, scrubbing, saved-session reopen, decoded file input, and the voice source. The four 30-second prepared capture and loop buffers use about 132 MiB at 48 kHz before voice bank memory.

Still missing from the historical Main instrument: the full MidiSynth rack interface, its L1–L4 sample and Free capture sources, effects, and modulation path; Ableton Link and host transport; legacy preset import; and native packaging of this Main looper. The page’s piano keys expose the ported voice bank for testing. They are not a substitute for Lucas’s original MidiSynth surface. Session imports require the same sample rate and publish layers one at a time.
