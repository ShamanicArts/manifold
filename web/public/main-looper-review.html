Free mode uses two presses of the original Cap control. What is connected

First LoopREC measures the selected layer’s input span. Stop infers legal bars and BPM nearest the Target value, then commits audio to that layer.
Retrospective captureAll four layers keep 30 seconds of input. The nine bar regions select recent history without a preceding REC action.
Four playable layersIndependent loop PCM, position, volume, mute, signed speed/reverse, seek/scrub, play/pause, and clear. Dry input and loop output mix as in Main.
Other modes and persistenceFree Mode quantizes at the current tempo. Traditional arms a segment for explicit fire. Both commit-based overdub length policies are in Rust. Version 3 session JSON saves four loops, the captured Main Sample PCM, Source, ADSR, Filter, FX1, FX2, EQ, and the connected LFO route for same-rate reopen. Versions 1 and 2 remain importable.

Try the connected path

  1. Open the live port with Dry input set to None and start audio. Hold a piano key, then release it.
  2. Click the 1/16 segment to make a retrospective loop from that note. Select another layer and repeat with a different note.
  3. Select Test tone before starting audio again. Press REC for roughly one second, then press it again. First Loop infers BPM near Target and fills the active layer.
  4. Select another layer, click 1/4, and hear recent input loop beside the first layer. Traditional mode arms a segment for the separate Commit armed action.
  5. Download a session, restart audio, then open the file at the same sample rate. Waveform scrubbing, signed speed, mute, and per-layer play controls are available.

Proof and boundary

The Rust workspace tests pass, including dry-only Live sample capture, playback and chronological Sample graph peak probes. Direct Wasm checks verify First Loop timing, a dry-input retrospective commit, ADSR attack, shared SVF mode response, two serial FX slots, and the eight-band EQ response on the Rust voice, a Main note saved into another layer, and Retro/Free Sample capture and playback. Chromium checks the legacy y=52 capture and y=182 tab offsets, switches the Looper/MidiSynth views, drags ADSR Attack and Filter cutoff/resonance, changes an FX type and its XY/mix controls, edits and removes an EQ band, and exercises First Loop, Live/L1 Retro Cap, L1 Free Cap/STOP, the Sample waveform and Source tabs, Traditional arm/fire, scrubbing, saved-session reopen, decoded file input, and the voice source. The four 30-second prepared capture and loop buffers use about 132 MiB at 48 kHz before voice bank memory.
