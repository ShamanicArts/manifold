One face, two control inputs

Selecting Slew OUT for IN replaces the LFO input wire. Selecting Manual gate removes the EOC trigger wire. The browser test also switches Filter routing from OUT to INV, saves and reopens it, then drags Sample Hold onto LFO’s occupied cell.

What was checked

Browser and Wasm

Muted Chromium connected OUT and INV to Filter CUTOFF through the Rust AudioWorklet, changed both input selectors, saved and reopened the state, and verified occupied-cell reflow and cable positions.

Native signal

The browser session prepared in native Main. A sounding note changed by more than 10% in measured energy when the restored Sample Hold route was enabled. Native validation rejected a mismatched input selector.

Portable state

The rack catalog names both input dependencies and both Filter output routes. Native export reconciles the signal and trigger cables when host controls change. CLAP and VST3 roundtrip checks include the browser session.

Current boundary

IN and TRIG cables follow their source selectors; the Patch sockets show those connections but direct input cable gestures remain ahead. The packaged native editor displays control cables read only. Additional destinations still use the separate route controls. Dynamic module insertion, deletion, and general control graph publication remain open.
