Evidence and limits

A native Rust graph and the Wasm AudioWorklet render the same two-note schedule for 8,192 stereo frames at 48 kHz, sample for sample. The browser check confirms typed route selection, on-screen note input, +7 and +12 emitted pitches, live Rust parameter acknowledgement, and project save/reopen. The fixed reference capture stays at +7; live edits do not rewrite that evidence.

The embedded browser may not grant hardware MIDI permission. The on-screen keyboard works without it. To use hardware MIDI in another browser, open the workspace there and import the downloaded graph project first. This graph is a v2 voice study, not a complete port of the old Main instrument. Sample assets and live plan replacement remain ahead.
