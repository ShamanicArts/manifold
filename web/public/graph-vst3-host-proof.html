What this proves

FactoryREAPER finds Manifold Graph alongside the original Standalone FX class in one bundle. Steinberg's validator exercises both classes.
Signal pathA VST3 note event reaches the Rust graph at frame 16 and produces the same 128 frame stereo output as direct native rendering, sample for sample.
Full host renderA one second MIDI item in REAPER matches direct native Rust audio over all 48,000 stereo frames to 24-bit WAV quantization. The repeatable probe saves the WAV and measurements.
Project stateThe component accepts and saves a portable graph bundle. A test loads a sidechain to output route and verifies the VST3 sidechain bus produces the expected stereo samples. REAPER also loads a second authored graph via a standard preset file.
Host parametersAll 128 public IDs stay fixed while project bindings change. REAPER reports 131 parameters because it adds three host controls.
Editor round tripThe packaged VST3 editor shows the original widgets. REAPER automation updates a visible slider, a physical drag reaches REAPER's parameter, and a preset change rebuilds the node controls in the open view.
Direct importThe editor imports Tone Texture JSON, updates REAPER's fixed slots, and the processor persists it. A fresh-process render matches the preset path exactly over 48,000 stereo frames.
Embedded PCMA 513 KB browser project with one second of stereo sample data imports through the same editor path. REAPER's saved-project MIDI render matches direct native Rust within 5.96e-8 peak error.

Current boundary and next work

Direct editor import is verified in REAPER on Linux through a 513 KB embedded-sample project. The native file chooser also selected a Tone Texture JSON file; REAPER saved and reopened that imported graph with the same audio result. Other hosts may cap private VST3 message sizes. The browser workbench and native graph editor now support deliberate host slot reassignment, each with a fresh-process REAPER audio proof. An existing REAPER envelope also retargets after an occupied-slot swap and renders against native Rust. Routing for multiple MIDI input nodes and broader host validation remain. The earlier Standalone FX class has its own original widget editor and independent host proof.

Reproduce: cargo test -p manifold-vst3, ./scripts/build-vst3.sh, validator -e target/vst3/ManifoldFX.vst3, then run scripts/probe-reaper-graph-vst3.py and scripts/probe-reaper-graph-vst3-gui.py in normal, --direct-import, --sample-import, and --manual-picker modes on an isolated Xvfb display. To export your own graph: cargo run -p manifold-vst3 --example export_graph_preset -- my-graph.json my-graph.vstpreset.
