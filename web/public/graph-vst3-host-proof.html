What this proves

FactoryREAPER finds Manifold Graph alongside the original Standalone FX class in one bundle. Steinberg's validator exercises both classes.
Signal pathA VST3 note event reaches the Rust graph at frame 16 and produces the same 128 frame stereo output as direct native rendering, sample for sample.
Full host renderA one second MIDI item in REAPER matches direct native Rust audio over all 48,000 stereo frames to 24-bit WAV quantization. The repeatable probe saves the WAV and measurements.
Project stateThe component accepts and saves a portable graph bundle. A test loads a sidechain to output route and verifies the VST3 sidechain bus produces the expected stereo samples. REAPER also loads a second authored graph via a standard preset file.
Host parametersAll 128 public IDs stay fixed while project bindings change. REAPER reports 131 parameters because it adds three host controls.

Current boundary and next work

This general graph class currently uses the host's generic controls. Its native graph editor and direct in-editor project import are next. Only the first MIDI input node receives host notes for now. The earlier Standalone FX class retains its original widget editor and independent host proof.

Reproduce: cargo test -p manifold-vst3, ./scripts/build-vst3.sh, validator -e target/vst3/ManifoldFX.vst3, then run scripts/probe-reaper-graph-vst3.py on an isolated Xvfb display. To export your own graph: cargo run -p manifold-vst3 --example export_graph_preset -- my-graph.json my-graph.vstpreset.
