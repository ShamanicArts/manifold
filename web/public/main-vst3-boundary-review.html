Main now has its own
VST3 audio and state path.

The packaged Main class is a separate VST3 instrument around the same Rust runtime used by the browser and CLAP. Its processor handles stereo audio, timed MIDI and automation, and portable Main sessions. The controller presents the 204 real Main parameter IDs to the host.
