Save and reopen this study

Use “Download project state” in the workbench to save six graph controls, target mode and recipe, temporal position, and the source. A file source is embedded as stereo float32 PCM; the built-in tone is saved as a source choice. Opening a state while stopped re-runs Rust/Wasm analysis and target preparation, then restores pitch and branch gains. The state is versioned and rejects malformed audio or out-of-range controls.

A 30-second 48 kHz stereo source produces roughly 15 MB of base64 audio in JSON. This saves the decoded source, not the original file encoding or old Lua project state.
