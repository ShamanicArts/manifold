Save and reopen this study

Use “Download project state” in the workbench to save 21 graph controls, target mode and recipe, temporal position, and the source. The phrase reference starts from analyzed source RMS and can be adjusted manually. A file source is embedded as stereo float32 PCM; the built-in tone is saved as a source choice. Opening a state while stopped re-runs Rust/Wasm analysis and prepares both bank targets, then restores pitch and branch gains. Version-7 state accepts prior versions 1–6; older files open with sample stage gain 1.

A 30-second 48 kHz stereo source produces roughly 15 MB of base64 audio in JSON. This saves the decoded source, not the original file encoding or old Lua project state.

Legacy boundary and next route

The compiled C++ comparison isolates the old gain, crossfade, and two mixer stages with the same fixture source. It establishes that chain's amplitude behavior, including both centre-pan reductions; it does not prove the complete old voice output or full project presets. The next calibration couples one voice amplitude to oscillator, sample, and Add sources. FM/Sync direction behavior and voice allocation follow. Old Morph forces the Add crossfade to its source endpoint; this v2 study keeps that position manually adjustable. The old Main voice checks an optional ADSR field but never constructs or connects that node, so note ADSR would be a deliberate v2 behavior.
