Legacy boundary and next route

The old Main voice uses 1 − depth and depth for its base and Add gains in Add/Morph modes. That gain law is now available as a linked option, while independent audition controls remain for comparing the two branches. This is native Rust versus Wasm graph evidence; old sample/oscillator amplitude staging and full C++ Main output are not yet calibrated. FM/Sync direction behavior, voice allocation, and old presets remain. Old Morph forces the Add crossfade to its source endpoint; this v2 study keeps that position manually adjustable. The old Main voice checks an optional ADSR field but never constructs or connects that node, so note ADSR would be a deliberate v2 behavior.
