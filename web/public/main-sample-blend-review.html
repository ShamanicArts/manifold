Main pitch joins FM and Sync in Rust

The Main study updates wave pitch and sample speed once per audio block for FM, then resumes or retriggers sample playback on Sync wraps. Save and reopen this study

Use “Download project state” in the workbench to save 33 graph controls, target mode and recipe, temporal position, and the source. A file source is embedded as stereo float32 PCM; the built-in tone is saved as a source choice. Opening a state while stopped re-runs Rust/Wasm analysis and prepares both bank targets, then restores its graph controls. Version-11 state accepts prior versions 1–10; older files open in Normal direction mode with mapped pitch off.

A 30-second 48 kHz stereo source produces roughly 15 MB of base64 audio in JSON. This saves the decoded source, not the original file encoding or old Lua project state.

Legacy boundary and next route

The 13-block legacy trace proves the original Lua control decisions for the chosen positions, levels, and mode transitions. The compiled C++ reference proves the isolated oscillator hard-sync kernel. The authored v2 Main graph does not yet reproduce the entire old voice: per-note gate and allocation, Ring mode, Add oscillator routing, Morph selection, and old presets remain. The present direction and pitch controllers update one authored voice at each Rust audio block. The old Lua pitch trace validates isolated mapping decisions, while the five new audio cases validate the authored Rust/Wasm graph; the complete old Main voice is not yet compared. The old Main voice checks an optional ADSR field but never constructs or connects that node, so note ADSR would be a deliberate v2 behavior.
