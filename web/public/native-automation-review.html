The whole MIDI and automation queue is checked before output changes. Unknown IDs and invalid events leave the destination buffer intact. Event scratch is reserved during preparation and reused during rendering. Browser projects retain their current control values as physical units; the native adapter maps the host's normalized range onto those units.

The ID is derived from the graph node and local control ID, so it stays stable while that node remains. A VST3 controller will need a fixed enumeration policy when graph edits add or remove nodes. This checkpoint is a native Rust library, not yet a loadable plug-in or a browser automation editor.
