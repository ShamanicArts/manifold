The control path

01 / Edit

Set a value

The editor validates the parameter against its node’s declared range and sends one request to the AudioWorklet.

02 / Apply

Rust decides

The worklet calls the Rust/Wasm node setter and returns an accepted or rejected result.

03 / Keep

Save accepted state

Only an accepted value updates the graph project. Rejection restores the displayed value.

Try the boundary

  1. Start the default graph with the test oscillator. Move Gain 2 → Level from 0.7 to 0.35; audio continues and the project records 0.35.
  2. Stop audio, add a Noise node without connecting it to Output, then restart. Its parameter cannot change live because Rust prunes that unreachable node. Connect it to Output on the next stopped edit to make its controls live.
  3. Download the project after an accepted edit and reopen it: the value survives. The three native/Wasm reference cases below the workbench remain independent fixed captures.
