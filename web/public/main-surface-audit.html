What the measurements do and do not show

The fixed Looper shell and live capture plane.

The visual capture bins now enter each strip on the left and age toward the right, following the requested display behavior. The historical C++ peak bucket order differs. These measurements verify static layout and color values, not a pixel-identical render of JUCE text or every widget. The browser host header, session controls, and help below the instrument are additional web controls. The MidiSynth rack is still incomplete; its ported module faces are reviewed separately.
