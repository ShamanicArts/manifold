What changes in the engine

stereo input→bounded ring→ordered snapshot→new-note source

One AudioWorklet message handler copies the ring oldest to newest, including after wrap, and publishes that same window to the Rust instrument between render calls. A transferable PCM copy becomes the graph project asset for save and reopen. The older “Use stopped take” control still requires recording to stop.

The deterministic worklet check exercises publication during recording, continued capture, held-note source continuity, new-note adoption, the stopped-take gate, and the sidechain input. The Rust ring test checks ordering after wrap. The full Rust workspace tests and browser build pass.

Publication cost

A synthetic Node run of the actual Wasm worklet handler with a full two-second stereo window at 48 kHz measured 1.18 ms median, 1.83 ms p95, and 2.27 ms maximum over 30 publications. A 128-frame quantum at that rate is 2.67 ms. This probe excludes browser message transfer, the physical audio device, and underruns; it is a cost signal, not a glitch-free guarantee.

This is a user-triggered snapshot, not an always-running retrospective capture service. Publication allocates and copies in a worklet message handler on the audio thread. Frequent or automatic publication needs staged transfer and an underrun measurement first. The two-second study is bounded; its sample data is saved with the graph project.
