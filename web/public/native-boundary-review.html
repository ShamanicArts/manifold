Manifold v2 / native boundary checkpoint / 27 September 2026

The same graph now has a native host edge.

A new Rust adapter prepares and renders the Manifold graph for native hosts. It accepts separate stereo main and sidechain buses, variable block lengths, and timed MIDI events. The browser and native paths continue to share the same DSP crate.

The native adapter validates channel lengths, block capacity, and timed MIDI offsets before touching output. Missing buses are silence. Graph state and scratch are prepared before the process call; the process method adds no allocation.

Native tests render main plus sidechain, each bus alone, and missing-bus silence. An oversized block and mismatched channels leave output untouched. A note begins only after its scheduled offset; an out-of-range event is rejected without changing the output. The earlier browser and native/Wasm graph comparisons remain the DSP baseline.
