Sources have their
own identity again.

Legacy Standalone Sample defines source 0 as Audio Input and source 1 as Sidechain. The graph needs separate node IDs to run their capture rings. The portable project now records both identities explicitly, so a graph edit does not turn a node number into a user-facing source name.

New capture nodes can be registered with a name in the stopped graph editor. A source ID is assigned without changing the node ID. The editor also supports renaming and removal. Selection writes both the source ID and capture node ID to the project bundle.

What crosses each boundary

Browser project

captureSources, default source ID, and selected source ID are saved alongside the graph. A Chromium test renamed a source, exported it, reopened it, registered a third source, removed it, and captured both original rings.

Native Rust loader

The loader rejects duplicate IDs, duplicate node mappings, missing names, invalid capture nodes, or a selected source that disagrees with the selected node. Old bundles without a registry still load.

CLAP and VST3 editors

Both host presentation snapshots include source names and IDs. The shared compact editor shows them in its capture selector, while its commands keep using stable graph node IDs for the audio mailbox.

Published sample

Native capture replacement updates the selected source ID together with the node ID, then saves the resulting PCM asset in the existing portable project format.
