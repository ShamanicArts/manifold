Signal and state proof

The historical Lua Scale Quantizer tests pass. Native Rust verifies two simultaneous voices, live retuning, retained source-note ownership, and source-note release. Direct Wasm measures held C♯4 sounding as C4, then D4 after Direction changes to Up: 335 versus 375 rising crossings over equal windows. Chromium edits all three dropdowns, connects the voices, displays the active mapping, saves and reopens version 11, imports version 10 with the voice connection off, and opens the direct module link.

The voice stage is prepared inside the Rust bank; no heap work occurs in the audio block. Main currently exposes one Scale Quantizer stage fed by MidiSynth voices. Multiple voice modules, arbitrary voice-bundle patching, and the remaining historical rack surfaces still need porting.
