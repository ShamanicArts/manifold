Signal and state proof

Native tests cover trigger edges, Sample, Track and Step modes, OUT/INV route polarity, state restore and source validation. A direct Wasm check routes Sample Hold OUT through FX1 mix and measures equal-window held-note energy changing from 4.79 to 26.90. Chromium changes the live controls, checks trigger status, saves version 7 with the held value and trigger edge, reopens it, imports version 6 defaults, and opens the direct module link.

The prepared chain is LFO → ATV → Slew → Sample Hold → routes. It has one Sample Hold instance. LFO end-of-cycle triggers are aggregated for each audio block and sample the selected input at the end of that block; exact within-block edge sampling and the wider legacy patch graph are still open.
