The signal path

MIDI slot → wave + processed sample → [wave × sample] / [sample × wave] → equal-power blend → two voice gain stages → stereo sum

Two directions

One prepared Ring kernel takes the wave as carrier and sample as modulator; the other takes the sample as carrier and wave as modulator. Blend chooses between their results. The old graph uses these crossed audio buses, so the Rust kernels receive explicit external modulators.

Mode and depth

Normal, Ring, FM, and Sync are selected on one control. Ring depth uses the existing branch-depth control; zero depth reproduces the unmodulated base blend in the core test. Switching mode changes held notes without constructing DSP objects in the callback.

Evidence

The new Ring chord capture matches native Rust and Wasm sample for sample. The AudioWorklet check switches a held chord into Ring mode and compares it with a separate unmodified control instance. Seven of the eight bank captures are bit-exact; the earlier vocoder chord retains its measured bounded variance of 0.004962 peak and 0.000350 RMS.

This verifies the v2 Ring route and its browser transport. It does not yet prove full old Main voice audio parity: the per-voice ADSR runs at sample rate in v2, and Add/Morph plus full project state are still being connected. The embedded BB browser cannot grant hardware MIDI access; the on-screen keyboard is available.
