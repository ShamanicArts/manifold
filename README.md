# Manifold v2

The new Manifold core: portable Rust DSP, a browser AudioWorklet host, and a JavaScript interface. The primitive library has 16 interactive views, from filter and voice basics through modulation, effects, loop capture, the original eight-band Spectrum Analyzer, and Envelope Follower. Analyzer and follower cases compare both audio and meter snapshots with C++; composed v2 projects compare native Rust with Rust/Wasm. It is an independent jj history on the `manifold-v2` branch of the existing [Manifold repository](https://github.com/ShamanicArts/manifold). Legacy Lua supplies behavior and visual references only; no Lua is loaded into v2.

## Try the primitive workbench

Requirements: Rust with `wasm32-unknown-unknown`, Node.js, and a modern browser.

```sh
cargo test --workspace
./scripts/build-wasm.sh
npm --prefix web ci
npm --prefix web run dev
```

Open the Vite URL and choose a primitive from the library. Each view has working controls and a direct link such as `?primitive=envelope-follower`. For Voice synth, click **Start instrument** and play its keyboard or A–K shortcuts. **Connect MIDI input** calls the browser permission API on click; a browser policy may block that request, and the workbench reports detected policy blocks. To try hardware MIDI, open the same localhost URL in an external browser with Web MIDI support. The on-screen keyboard works without MIDI permission. Other views use the test oscillator or microphone. Loop capture records a short stereo phrase and plays, reverses, slows, or overdubs it. Spectrum Analyzer passes stereo audio through and exposes eight legacy band estimates; its bands are one-pole envelopes, not FFT bins. Envelope Follower also passes audio through while metering peak, RMS, or hybrid level with a visible recent history. All 89 offline cases should show **Match**: 61 C++ cases and 28 native Rust cases, each compared with Rust/Wasm.

The browser page works without an external audio interface; microphone mode requests browser permission. The workbench uses Canvas 2D for measurements. The Three.js/WebGPU module remains available for later spatial and media project views.

To check native Rust against the original C++ samples, run `python3 scripts/check-svf-parity.py`, `python3 scripts/check-crossfader-parity.py`, `python3 scripts/check-mixer-parity.py`, `python3 scripts/check-oscillator-parity.py`, `python3 scripts/check-adsr-parity.py`, `python3 scripts/check-noise-parity.py`, `python3 scripts/check-distortion-parity.py`, and `python3 scripts/check-stereo-delay-parity.py`. The fixtures are checked in, so this does not need the old checkout. To regenerate them from an old checkout, run the matching `scripts/generate-*-reference.py`; set `MANIFOLD_LEGACY_DIR` if that checkout is not at `../my-plugin`. Regeneration compiles the original C++ node into a standalone runner and does not edit the old repository. Mixer, Oscillator, and ADSR fixture generation also need `pkg-config` and Highway (`libhwy`). Voice, synth patch, modulation, FX chain, effect-slot, and loop-capture fixtures come from their `scripts/generate-*-reference.py` scripts and need only the Rust workspace.

The first slices include the original filter modes, Crossfader, Mixer, five Oscillator waveforms, ADSR, stereo noise, composed synth and FX chains, a two-type Standalone FX slot slice, bounded loop capture, scalar Distortion and StereoDelay, typed CV ports, timed note events, and an eight-voice instrument. The Spectrum Analyzer and Envelope Follower use bounded meter readouts independent of audio rendering. Precise external MIDI timestamps, sustain pedal, sample-rate follower-to-CV routing, host automation, preset conversion, OSC, retrospective capture, full looper behavior, true FFT analysis, and native plug-in packaging remain.
