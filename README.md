# Manifold v2

The new Manifold core: portable Rust DSP, a browser AudioWorklet host, and a JavaScript interface. The primitive library has 45 interactive views, from filter and voice basics through audio/CV slew, effects, loop capture, the original eight-band Spectrum Analyzer, Envelope Follower, and an authored envelope ducking project. Analyzer and follower cases compare both audio and meter snapshots with C++; composed v2 projects compare native Rust with Rust/Wasm. It is an independent jj history on the `manifold-v2` branch of the existing [Manifold repository](https://github.com/ShamanicArts/manifold). Legacy Lua supplies behavior and visual references only; no Lua is loaded into v2.

## Try the primitive workbench

Requirements: Rust with `wasm32-unknown-unknown`, Node.js, and a modern browser.

```sh
cargo test --workspace
./scripts/build-wasm.sh
npm --prefix web ci
npm --prefix web run dev
```

Open the Vite URL and choose a primitive from the library. A direct picker stays available above the desktop library list; on narrow screens it replaces the long list so the active workbench remains close to the top. Each view has working controls and a direct link such as `?primitive=voice`. For Voice synth, click **Start instrument** and play its keyboard or A–K shortcuts. The Voice view shows recent note events from the keyboard or a connected device. **Request MIDI access** calls `navigator.requestMIDIAccess()` on click where the API and page policy allow it. The in-app browser may leave the permission request pending without a prompt; after four seconds the page explains this, keeps a Stop waiting control available, and offers a selectable absolute URL to open in an external browser with Web MIDI support. The on-screen keyboard works without MIDI permission. Hardware MIDI note events use their browser timestamps to reach within-block offsets when they arrive with enough lead time; late events play at the next block. MIDI sustain pedal CC64 merges by channel across inputs and holds released notes until the final pedal-up, while each input and the on-screen keyboard keep separate note ownership. A 14-bit pitch bend message reaches the Rust instruments at a timed audio frame and bends only its MIDI channel; the on-screen wheel lets you test it without MIDI permission. Other views use the test oscillator or microphone. Loop capture records a short stereo phrase and plays, reverses, slows, or overdubs it. After stopping Record, send the take to Sample instrument for keyboard playback or to Granulator for a grain cloud. Sample region accepts an audio file up to 30 seconds, decoded before the worklet loads it; a built-in example is available immediately. Start the instrument, then click **Trigger sample**. The stereo waveform shows play and loop markers, the editable crossfade span, and a live playhead. A separate Rust/Wasm worker reports stereo peaks, RMS, and a pitch estimate; in Sample instrument, **Use detected root** applies a reliable suggestion only when clicked. Stop the instrument before choosing another file. The Sample instrument view plays the same source with eight note voices and up to four detuned, stereo-spread subvoices per note, plus root-note pitch mapping, a keyboard, optional MIDI input, and adjustable note release. Spectrum Analyzer passes stereo audio through and exposes eight legacy one-pole band estimates. The separate FFT spectrum view uses 32 logarithmic bands and reports the strongest peak in hertz. The Granulator view compares capture-ring and preloaded-source grains with zero-spray C++ references; choose an audio file before starting to use a fixed source and its region controls. Seeded spray runs live in Rust. The Shimmer view compares its pitched, modulated delay and filtered feedback with the C++ node. The Pitch Shifter view compares its overlapping stereo heads, feedback, and dormant bypass with the C++ node. The Stutter view compares seeded pattern, probability, gate, and beat length with the C++ node. The Reverse Delay view compares backward stereo windows, feedback, and dormant bypass with the C++ node. The Formant filter view morphs among five vowels with C++ parity captures. The separate three-band EQNode view exposes low and high shelves plus a peaking mid band with eight C++ captures. The Standalone EQ8 view exposes eight switchable bands with seven filter types, a Rust-derived live response curve, and C++ parity captures. The WaveShaper view exposes seven curves, drive, bias, tone filters, mix, and its legacy coefficient mode with eleven C++ captures; its normalized type 2 controls also work in the Standalone FX slot. The FilterNode view exposes its separate two-pole lowpass with C++ Highway and scalar captures. The Stereo widener view exposes width, mono low cutoff, and a live Rust correlation meter with eight C++ audio and meter captures. The Stereo phaser view sweeps six or twelve all-pass stages with adjustable feedback and phase spread; Stereo chorus layers one to four modulated delay voices. Each has seven C++ captures. Slew limiter shapes stereo rises and falls; the Slew modulation patch applies the same rule to a typed CV path before gain modulation. The CV rack slice now combines sample-and-hold, attenuverter/bias, and a four-input CV mixer at sample rate, with live readouts for each stage and effective gain. Its eight CV routes and ten public controls can be downloaded and reopened as a v2 JSON patch while audio is stopped. In the LFO, slew, CV rack, and envelope ducking projects, the base gain slider also shows a read-only effective gain snapshot from the Rust graph. Envelope Follower also passes audio through while metering peak, RMS, or hybrid level with a visible recent history. Envelope ducking uses the same detector as a sample-rate CV source for a gain stage. Compressor and Limiter show live gain reduction and compare their original C++ audio and meter outputs. Standalone FX remembers its selected type and controls while visiting other views, and can download and reopen a v2 JSON state for all 21 effects across reloads. A separate Rust routing primitive now matches the old C++ Gain/Mixer envelope; an isolated Chorus/Delay switch with persistent tails also matches the old kernels. The separate Standalone FX tails view runs that persistent Rust/Wasm slot live and compares a Delay → Chorus → Delay switch with isolated old C++. It saves controls in a separate version 2 JSON document; internal audio tails restart when the graph restarts. The FX host switch view reconstructs the old C++ branch graphs for Delay → Chorus or Phaser → Delay and return visits to Compressor, SVF, Reverb, Ring Mod, Transient Shaper, BitCrusher, or Stereo Widener, including gate snapping, Compressor timing refresh, SVF state retention, Reverb tail clearing, the old Ring Mod empty-bus behavior, Transient envelope reset, BitCrusher held-sample reset, and Stereo Widener low-band/correlation reset. Its live controls cover the ten effects whose graph behavior has been audited; it does not yet support the all-type state document. Full project capture remains. Choosing an effect also selects a matching offline comparison case. Import is available while audio is stopped. All 383 offline cases should show **Match**: 239 C++ cases and 144 native Rust cases, each compared with Rust/Wasm.

The CV rack has a Control patch section for eight typed CV inputs. Ring Modulator has an Audio patch section that switches its optional modulation bus between the internal oscillator and a copy of live stereo input while audio runs. Rust updates each route at the next audio block; disconnected nodes park and retain their state. Edits stay in this page session, and a full restart resets graph state. The browser page works without an external audio interface; microphone mode requests browser permission. The workbench uses Canvas 2D for measurements. The Three.js/WebGPU module remains available for later spatial and media project views.

To check native Rust against the original C++ samples, run `python3 scripts/check-svf-parity.py`, `python3 scripts/check-crossfader-parity.py`, `python3 scripts/check-mixer-parity.py`, `python3 scripts/check-oscillator-parity.py`, `python3 scripts/check-adsr-parity.py`, `python3 scripts/check-noise-parity.py`, `python3 scripts/check-distortion-parity.py`, `python3 scripts/check-stereo-delay-parity.py`, `python3 scripts/check-phaser-parity.py`, `python3 scripts/check-chorus-parity.py`, and `python3 scripts/check-slew-audio-parity.py`. The fixtures are checked in, so this does not need the old checkout. To regenerate them from an old checkout, run the matching `scripts/generate-*-reference.py`; set `MANIFOLD_LEGACY_DIR` if that checkout is not at `../my-plugin`. Regeneration compiles the original C++ node into a standalone runner and does not edit the old repository. Mixer, Oscillator, and ADSR fixture generation also need `pkg-config` and Highway (`libhwy`). Voice, synth patch, modulation, slew modulation, CV rack, FX chain, effect-slot, loop-capture, sample-region, sample-instrument, and envelope-ducking fixtures come from their `scripts/generate-*-reference.py` scripts and need only the Rust workspace.

The first slices include the original filter modes, Crossfader, Mixer, five Oscillator waveforms, ADSR, stereo noise, composed synth and FX chains, a twenty-one-type Standalone FX slot slice, bounded loop capture, file-backed sample-region playback, a shared-buffer eight-voice sampler, scalar Distortion, WaveShaper, StereoWidener, FilterNode, Compressor, Limiter, StereoDelay, Phaser, Chorus, Reverb, MultitapDelay, RingModulator, TransientShaper, BitCrusher, and the three-band EQNode, FormantFilter, ReverseDelay, Stutter, PitchShifter, Shimmer, and Granulator, typed CV ports, timed note events, and an eight-voice instrument. Spectrum Analyzer, FFT spectrum, Envelope Follower, Compressor, and Limiter use bounded meter readouts independent of audio rendering; `EnvelopeControl` also provides sample-rate CV without browser timing in the signal path. Hardware MIDI latency calibration, other MIDI controllers, host automation, preset conversion, OSC, retrospective capture, full looper behavior, and native plug-in packaging remain.
